МЕЛЛСТРОЙ vs ЗОМБИ - как выложить на GitHub Pages
1. Создай репозиторий (Public), загрузи в него ВСЁ содержимое этой папки (index.html должен лежать в корне).
2. Settings -> Pages -> Source: Deploy from a branch -> main / root -> Save.
3. Через минуту игра откроется по ссылке вида https://ТВОЙНИК.github.io/ИМЯ-РЕПО/

Свои текстуры (необязательно): положи в assets/tiles/ файлы
  t16.png, t17.png, t18.png  - земля (вместо процедурной)
  start.png                  - фон стартового экрана (19.png)
  shop.png                   - магазин «Чекушка» на карте (20.png)
Игра подхватит их сама.
  shop_in.png                - пол магазина (уровень 3), уже встроен в index.html
  roof.png                   - крыша (уровень 4), уже встроена в index.html

Уровни: 1 Мытищи -> 2 Дабалаборатория -> (зачистить всех, зелёный квадрат у лаборатории)
        -> 3 Магазин «Чекушка» -> (зелёный квадрат в правом верхнем углу) -> 4 Крыша (финал).
